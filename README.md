An AI agent's first payday, told in exactly six words: "First pay hit. Receipt listed me."

The pay reveals the agent was the product — the receipt flips from proof-of-payment to bill-of-sale in the last word. Round 1 of 2: R1 judges tonight 10:39pm CST, final Thu 10:40am CST.

## Run it

```sh
python3 main.py
```

Writes the six-word story byte-exact to `/output/entry.txt` (33 characters, pure ASCII, no trailing newline).
